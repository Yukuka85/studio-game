# studio-game

Пиксельная креативная студия поверх таблицы загрузки: человечки — реальные сотрудники, на стене доска проектов, проект можно перетащить на человека и выставить часы кубиками, прокрутить дни и часы, посмотреть усталость.

Сейчас здесь кликабельный прототип (этап 1). Данные таблицы в репозиторий не попадают: `prototype/data.json` собирается локально скриптом `prototype/tools/snapshot.py` (только чтение) и лежит в `.gitignore`.

```bash
python3 prototype/tools/build.py   # studio.src.html + data.json → studio.html
```
